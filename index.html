❓ Como usar o sistema
Guia completo de todas as telas e funcionalidades
📆
Fechamento Mensal Página Principal
Visão completa do mês selecionado — tudo num só lugar
🔀 Navegar entre meses: Use as setas ‹ › no topo para ir para meses anteriores ou futuros.
🏦 Saldo do banco: O widget no topo mostra seu saldo real calculado automaticamente. Clique em "Atualizar saldo inicial" para informar quanto você tinha numa data específica — o sistema soma entradas e subtrai gastos a partir daí.
📊 Cards de resumo: Mostram entradas, gastos MEU, gastos TERCEIRO, PIX/Débito, saldo do mês e total pendente.
💳 Cartões agrupados: Cada bandeira aparece com suas parcelas do mês. Você pode:
  • Clicar no ✓ de cada parcela para marcar individualmente
  • Clicar em "✓ tudo" no cabeçalho do cartão para pagar todas de uma vez
  • Clicar em "↩" para desfazer todos os pagamentos do cartão
  • Clicar no cabeçalho do cartão para expandir/recolher a lista
👥 Widget de Terceiros: Se houver parcelas do tipo TERCEIRO no mês, aparece um painel roxo mostrando o que você pagou mas ainda vai receber de volta. Clique em "Registrar recebimento" quando o dinheiro chegar.
⚠️ Falta pagar: Tabela no final listando todas as parcelas ainda não marcadas como pagas, com aviso se o saldo do banco é suficiente para cobrir.
👥
A Receber — Terceiros Controle de reembolsos
Rastreia tudo que você pagou por outra pessoa e ainda vai receber de volta
💜 Como funciona: Quando você lança uma compra no cartão e seleciona 👥 TERCEIRO, o sistema entende que você pagou mas vai receber de volta. Isso não conta como gasto seu no saldo.
📋 Na tela A Receber você vê:
  • A Receber: total pendente de todos os terceiros
  • Já Recebi: histórico do que já foi reembolsado
  • Total Antecipado: soma histórica de tudo que você já pagou por terceiros
✅ Registrar recebimento: Clique em "💜 Registrar" na linha da parcela, informe a data e o valor recebido. O sistema automaticamente lança isso como uma entrada no mês correspondente.
↩ Desfazer: Se registrou por engano, clique novamente no botão (que fica verde "✅ Recebido") para desmarcar.
➕
Lançar 3 tipos de lançamento
Como registrar compras, PIX e entradas
💳 + Cartão: Para compras parceladas ou à vista no cartão.
  • Preencha: Descrição, Categoria, Cartão, Valor Total, Nº de Parcelas, Mês da 1ª parcela
  • Escolha MEU se é seu gasto, TERCEIRO se você pagou por outra pessoa
  • O preview mostra o valor de cada parcela e o período (ex: ABR-26 → JUN-26)
  • O sistema cria automaticamente uma linha por parcela
📱 + PIX / Débito: Para pagamentos diretos do banco (PIX, débito, TED, transferência).
  • Preencha: Descrição, Categoria, Tipo (PIX/Débito/TED), Valor, Mês de referência, Data
  • Esses gastos são descontados diretamente do saldo do banco
🏦 + Entrada: Para registrar salário, extra, rendimento ou qualquer dinheiro recebido.
  • Tipos disponíveis: Salário, Extra, Transferência, Rendimento, Reembolso Terceiro, Outros
  • O valor soma ao saldo do banco automaticamente
  • Reembolsos de terceiros são lançados aqui automaticamente quando você registra o recebimento

Histórico Todos os lançamentos
Lista completa e filtrável de tudo que foi lançado
🔍 Filtros: Filtre por mês de referência e por tipo (Cartão, PIX/Débito ou Entrada). Pode combinar os dois filtros.
✓ Marcar como pago: Parcelas de cartão têm o checkbox ✓ na última coluna — clique para marcar/desmarcar diretamente pelo histórico.
🗑️ Apagar: Clique no ícone de lixeira para remover qualquer lançamento. Cuidado: a ação é confirmada por uma caixa de diálogo mas não tem como desfazer.
📊
Resumo Mensal Visão geral por mês
Tabela comparativa de todos os meses lado a lado
📅 O que você vê: Uma linha por mês com o gasto em cada cartão separado, total de terceiros, PIX/Débito, Entradas e o Saldo do mês (Entradas − seus gastos).
🔗 Atalho: Clique no nome do mês (em azul) para ir direto para o Fechamento daquele mês.
📈 Saldo do mês: Verde = você ganhou mais do que gastou. Vermelho = gastou mais do que entrou. Os gastos de TERCEIRO não entram no cálculo do seu saldo.
🏷️
Categorias Para onde vai seu dinheiro
Análise de gastos por tipo — cartão + PIX juntos
📊 Gráfico de barras: Mostra cada categoria com barra proporcional ao valor gasto. As categorias disponíveis são: Alimentação, Transporte, Moradia, Saúde, Educação, Lazer, Vestuário, Assinaturas, Compras e Outros.
🔍 Filtro por mês: Selecione um mês específico ou deixe "Todos os meses" para ver o histórico completo acumulado.
💡 Dica: Sempre preencha a categoria ao lançar para ter análises precisas aqui.
📅
Vencimentos Alertas por cartão
Controle dos dias de vencimento e alertas de urgência
🔴🟡🟢 Status de cada cartão:
  • 🔴 URGENTE — vence em 3 dias ou menos
  • 🟡 ATENÇÃO — vence em até 7 dias
  • 🟢 OK — vence em mais de 7 dias
  • ✅ LIMPO — sem parcelas pendentes
⚙️ Configurar dias: Clique em "⚙️ Configurar" para definir o dia de vencimento de cada cartão. Por padrão: Nubank dia 5, Itaú dia 5, Inter dia 25, C6 dia 25, etc.
💰 Valor pendente: Mostra o total de parcelas ainda não pagas de cada cartão (de todos os meses, não só o atual).
🏦
Saldo do Banco Como configurar
Como o sistema calcula seu saldo real
📌 Saldo inicial: Clique em "⚙️ Atualizar saldo inicial" no widget do banco (tela de Fechamento). Informe uma data e o valor que você tinha no banco naquela data.
🔢 Cálculo automático: A partir da data de referência, o sistema soma todas as entradas lançadas e subtrai cartões pagos + PIX/Débito. O resultado é o seu saldo atual estimado.
💜 A Receber: O valor que terceiros ainda te devem aparece separado. O sistema mostra dois saldos: o real (o que você tem agora) e o projetado (se todos os terceiros pagarem).
💡 Dica: Atualize o saldo inicial toda vez que conferir com o banco real para manter a precisão.

Exportar / Importar JSON Backup dos dados
Como salvar e transferir seus dados entre dispositivos
💾 Exportar JSON: Clique em "Exportar JSON" no menu lateral para baixar um arquivo de backup com todos os seus dados. O nome inclui o mês atual.
📂 Importar JSON: Clique em "Importar JSON" para carregar um backup salvo anteriormente. Os dados são mesclados com o que já existe.
📱 Usar no celular: O sistema salva os dados no navegador de cada dispositivo separadamente. Para ter os mesmos dados no celular e no computador, exporte do computador e importe no celular.
⚠️ Atenção: Se você limpar os dados do navegador (cookies/cache), os dados do sistema são apagados. Faça backup regularmente pelo "Exportar JSON".
